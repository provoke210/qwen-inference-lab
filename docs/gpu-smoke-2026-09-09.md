# AutoDL GPU smoke validation — 2026-09-09

Environment: NVIDIA GeForce RTX 4080 SUPER (instance exposes about 32 GiB),
PyTorch 2.8.0+cu128, Transformers 4.51.3, FlashAttention 2.8.3.
Model: Qwen/Qwen3-0.6B, BF16, single GPU.

## Bug found and corrected

`ModelRunner.prepare_decode` used `num_tokens - 1` for the valid cache length.
However, `Attention.forward` writes the current token's KV before invoking
attention. The length must be `num_tokens`; positions remain `num_tokens - 1`.
An in-memory A/B test with argmax sampling reproduced repeated/broken text
before correction and coherent text after correction.

Added GPU regression tests for lengths 1 and 257, including nonconsecutive
physical block IDs. The remote full test suite passed: **22 passed**.

## Post-fix smoke checks

0.25, maximum sequence length 512, batch-token budget 128, chunk size 64,
minimum prefill budget 32, maximum concurrent sequences 4.
Sampling was temporarily replaced with argmax in the diagnostic process;
the public sampling interface was not changed.

- Short prompt: “Please introduce yourself in one short sentence.”
- Short output: “I am a language model designed to assist with questions and
  provide information in various languages.” This text matched the separately
  run Hugging Face greedy reference for that prompt.
- Long prompt repeated “The secret number is 42.” 40 times and asked for the

- Repeating the long prompt with prefix caching enabled also produced `42`;

## Follow-up: CUDA Graph smoke and preliminary paired timing

Captured graph sizes 1, 2, 4. Added inference-mode capture and cleared stale
slot mappings before replay; padded lanes use slot -1 so they cannot overwrite
real KV entries when a graph is reused for a smaller batch. Added a metadata
regression test simulating a stale fourth lane. Remote suite: **23 passed**.
Local and remote model_runner/test files were verified identical by SHA-256.

Tested batches in order 4, 3, 1 with the short self-introduction prompt above,
prefix caching disabled, argmax sampling, max_tokens=32 and ignore_eos=True.
For each batch, one warmup pair preceded three measured pairs, alternating
eager/graph execution order. CUDA synchronization bracketed wall-clock timing
of generate(), including scheduling, prefill, decode and output conversion.
All generated token lists matched between eager and graph in all pairs.

| Batch | Eager median (ms) | Graph median (ms) | Ratio |
| --- | ---: | ---: | ---: |
| 4 | 1104.99 | 166.05 | 6.65x |
| 3 | 1033.34 | 129.08 | 8.01x |
| 1 | 957.38 | 123.19 | 7.77x |

These are preliminary within-project measurements, not vLLM comparisons.
Only one short prompt and three measured pairs were used; longer prompts,
mixed request lengths and more repetitions are needed before performance claims.
